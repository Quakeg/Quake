# 地震预警 Quake

基于网页的地震信息展示与预警工具，支持网页版和 Android。

---

## 功能

- 地震预警实时推送
- 地震历史记录查询
- 台风、海啸、火山、气象、灾害信息
- 测站数据展示
- P/S 波倒计时
- 底部滚动字幕
- 界面缩放、图例开关
- 自动定位
- 版本检测

---

## 数据来源

主数据源：

- WHEWS 地震预警聚合服务（JMA、CWA、CENC、KMA、USGS 等）

其他：

- USGS 美国地质调查局
- EMSC 欧洲地中海地震中心
- GFZ 德国地球科学研究中心
- BMKG 印尼气象局
- GEONET 新西兰
- NMC 中央气象台（台风）
- NMEFC 国家海洋环境预报中心（海啸）

---

## P/S 波倒计时

- 根据当前位置计算震中距
- 采用走时表推算 P 波、S 波到时
- 走时表基于 JMA 数据近似，含震源深度修正
- 显示预计到达倒计时

---

## 金钥申请

部分数据源需要金钥才能使用。

### 申请方式

在设置面板里点 **前往申请**，按提示提交申请，通过后会获得金钥。

### 填写方式

在设置面板里点 **前往 Token**，把金钥粘贴进去即可。

设置面板：底部导航 → **设置**

## 接口

| 接口 | 说明 |
|------|------|
| /all_eew | 所有地震事件 |
| /history | 地震历史 |
| /station | 台湾测站 |
| /station_kma | 韩国测站 |
| /station_summary | 测站汇总 |
| /quake_summary | 近期地震汇总 |
| /intensity_colors | 震度配色表 |
| /usgs | USGS 数据 |
| /typhoon | 台风数据 |
| /wave | 海浪数据 |
| /tsunami | 海啸数据 |

|------|------|
